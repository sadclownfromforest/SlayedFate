Script syntax 
send METHOD [expires=N] [max-forwards=N] [to=USER] [sdp=none|bad] [dialog]
ack                       # 2xx of the last INVITE (non-2xx are ACKed automatically)
auth [wrong]              # answer the last 401/407 with digest credentials
expect 180 183 [METHOD] [timeout=MS|ring]   # other 1xx are skipped
expect-request BYE [timeout=MS]             # request sent by the phone (answered 200)
wait MS
assert-header allow contains INVITE
